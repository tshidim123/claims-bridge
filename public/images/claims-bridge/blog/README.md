# Knowledge Hub artwork

Category-coherent editorial covers use an 8:5 master at 2000×1250. Name files `blog/{category-slug}/{article-slug}-cover.webp`; add a `-mobile` variant only when the composition is genuinely art-directed for portrait use.

See the editorial cover system and CB-VA-BLOG brief in `design-system/claims-bridge/visual-assets.md`. No stock imagery, generated text or one-off illustration styles.
